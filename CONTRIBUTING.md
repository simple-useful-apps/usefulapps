# Contributing

Thanks for wanting to help. Each Simple Useful App does one useful thing and
does not aspire to more, so the most welcome contributions keep it that way:
bug reports, fixes, and small improvements to what an app already does.

## Where things live

Each app has its own repository:

- [The Old Pod](https://github.com/mattreed555/theoldpod)
- [Chatfolio](https://github.com/mattreed555/chatfolio)

This repository is only the website. Each app's pages come from that app's
`docs/` folder, so changes to an app's page belong in the app's repository.

## Reporting a bug

Open an issue in the app's repository. Say what you did, what you expected,
what happened instead, and which device and OS version you were using.

## Suggesting a feature

Open an issue first and describe the problem it solves. A feature that makes an
app do something new, rather than do its one thing better, is likely to be
declined. That isn't a judgment of the idea; it may make a good app of its own.

## Sending a change

1. Fork the repository and make your change on a branch.
2. Keep it small and focused, and match the surrounding code.
3. Don't add dependencies, accounts, analytics, or network services.
4. Open a pull request explaining what changed and why.

By contributing, you agree that your work is released under the same license as
the project.
