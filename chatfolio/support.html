Help with Chat Folio.

iCloud Drive is unavailable

Chat Folio uses your iCloud Drive as its source library. Confirm that you are signed into iCloud, iCloud Drive is enabled, and Chat Folio is allowed to use it. There is no separate Chat Folio login.

A source is not ready

A newly added or newly downloaded source must be prepared before it can answer questions. Keep Chat Folio open to continue immediately, or let the resumable indexing job continue when the system allows. Use Retry from the source row if it reports a failure.

A source shows a cloud symbol

The source is in iCloud but is not fully downloaded on this device. Tap the download control while online. Other ready sources remain available while it downloads.

Chat is unavailable

Chat requires an on-device language model. The first download is large and can be paused or resumed. Confirm that the device has enough free storage and allow the download to finish. Library and Reader remain available in the meantime.

An answer does not contain the information

Chat Folio answers only from ready sources in the selected scope. Check the scope at the top of the chat and confirm that the relevant source has finished indexing. When the answer is not supported by the available passages, Chat Folio should say so.

A citation does not open the source

The saved quote remains visible even when the source is temporarily unavailable. Download the source from iCloud and try Open in Reader again. If the exact location cannot be recovered, Reader opens the nearest known heading.

A file cannot be added

Chat Folio supports EPUB, Markdown, HTML, and UTF-8 plain text. Encrypted or DRM-protected books, malformed archives, and unsupported files cannot be imported.
